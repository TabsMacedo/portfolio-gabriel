# Componente — Content

## Objetivo

Concentrar as informações que sustentam a apresentação profissional.

## Sobre

Deve responder, de maneira breve:

- quem é o desenvolvedor;
- qual sua área de atuação;
- quais interesses técnicos possui;
- qual abordagem utiliza no desenvolvimento.

## Projetos

Cada projeto deve possuir, idealmente:

- nome;
- descrição curta;
- problema ou objetivo;
- tecnologias;
- imagem/preview quando útil;
- link para projeto;
- link para repositório quando disponível.

## Habilidades

A seção deve mostrar tecnologias e competências relevantes sem transformar a página em uma lista infinita de ferramentas.

Possível organização:

- Front-end;
- Back-end;
- Ferramentas;
- Outros conhecimentos.

## Background

A proposta inicial é utilizar elementos flutuando lentamente.

Requisitos:

- movimento sutil;
- baixa prioridade visual;
- não interferir na leitura;
- não dificultar interação;
- respeitar redução de movimento.

**Ideia pendente:** investigar se existe uma interação sutil adicional que agregue valor sem virar distração.
