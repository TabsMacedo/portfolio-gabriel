# Componente — Footer

## Objetivo

Finalizar a experiência e oferecer caminhos claros para contato.

## Conteúdo

- e-mail;
- GitHub;
- LinkedIn;
- outros canais que façam sentido.

## Visual

A ideia inicial é utilizar um fundo monocromático, possivelmente cinza, para diferenciar o Footer do restante da página.

## Requisitos

- informações de contato devem ser fáceis de encontrar;
- links devem ser identificáveis como links;
- contraste deve ser suficiente;
- Footer deve funcionar bem em telas pequenas.
