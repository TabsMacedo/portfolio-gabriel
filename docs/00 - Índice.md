## Status do projeto

**Fase:** concepção / protótipo

**Objetivo atual:** transformar o protótipo em uma especificação suficientemente clara para iniciar a implementação sem perder liberdade para experimentar.

## Legenda

- `MVP` — necessário para a primeira versão funcional.
- `P1` — importante, mas pode entrar depois do MVP.
- `P2` — experimental ou de baixa prioridade.
- `Pendente` — decisão ainda não tomada.

## Princípio do documento

Este documento não é um contrato. Ele é uma ferramenta pessoal de desenvolvimento. Requisitos podem ser alterados quando uma decisão técnica, visual ou de usabilidade justificar a mudança.
