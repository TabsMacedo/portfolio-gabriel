# Visão do Projeto

## 1. Resumo

Criar um portfólio pessoal de web developer com foco em identidade visual tecnológica, experimental e contemporânea, apresentando quem sou, o que faço, projetos, habilidades e formas de contato.

O site deve funcionar como uma apresentação profissional pessoal, mas sem aparência excessivamente corporativa. A interface deve combinar informação objetiva com elementos visuais interativos que demonstrem capacidade técnica.

## 2. Conceito visual

A direção visual parte de uma estética tecnológica com:

- fundo escuro;
- branco azulado para informação principal;
- azul-cinza para informação secundária;
- ciano elétrico para interação;
- roxo para estados e ênfase;
- magenta para destaques especiais;
- elementos luminosos e sutis;
- sensação de interface experimental/holográfica.

## 3. Conceito central do Hero

O elemento visual principal será uma esfera luminosa azul/ciana.

Quando o cursor se aproxima, partículas roxas devem representar uma espécie de “infecção” ou “hacking” do objeto. Quanto maior a permanência do cursor, maior a influência roxa. Ao afastar o cursor, o objeto começa a retornar ao estado original.

O conceito é visual e metafórico: a esfera representa algo sendo hackeado/infectado.

## 4. Público

- recrutadores e pessoas avaliando o trabalho profissional;
- outros desenvolvedores;
- clientes ou possíveis colaboradores;
- visitantes interessados no trabalho do autor.

## 5. Resultado esperado

Ao terminar a primeira versão, um visitante deve conseguir rapidamente:

1. identificar quem é o desenvolvedor;
2. entender sua área de atuação;
3. conhecer seus principais projetos;
4. visualizar suas habilidades;
5. encontrar formas de contato;
6. navegar confortavelmente em desktop e dispositivos móveis.
