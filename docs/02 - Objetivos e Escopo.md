# Objetivos e Escopo

## Objetivos

### O-01 — Apresentação

Apresentar o desenvolvedor de forma clara e visualmente memorável.

### O-02 — Portfólio

Exibir projetos relevantes, seus contextos e tecnologias utilizadas.

### O-03 — Identidade

Construir uma identidade visual própria em vez de utilizar apenas um template genérico.

### O-04 — Demonstração técnica

Utilizar interações e animações com propósito para demonstrar domínio de desenvolvimento front-end.

### O-05 — Acessibilidade de informação

Permitir que informações importantes sejam encontradas sem depender das animações.

## Escopo do MVP

- página única / experiência principal de portfólio;
- Header fixo ou persistente durante a navegação;
- Hero;
- seção Sobre;
- seção Projetos;
- seção Habilidades;
- seção Contato/Footer;
- navegação por âncoras;
- responsividade;
- tema visual principal;
- links externos relevantes;
- elemento visual do Hero em uma implementação viável.

## Fora do escopo inicial

- painel administrativo;
- CMS;
- autenticação de usuários;
- área privada;
- sistema de comentários;
- banco de dados, salvo necessidade futura;
- blog completo;
- internacionalização avançada, caso PT/EN seja inicialmente apenas uma troca de conteúdo estático.

## Regra de escopo

Uma funcionalidade visualmente interessante não deve ser adicionada ao MVP se aumentar significativamente a complexidade, prejudicar performance ou dificultar acessibilidade.
