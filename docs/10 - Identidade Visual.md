# Identidade Visual

## Tipografia

### Títulos

**Orbitron**

Motivo: reforçar a associação tecnológica.

### Texto

**Inter**

Motivo: oferecer uma leitura mais neutra e equilibrar a aparência futurista dos títulos.

**Status:** validar em implementação real; pode ser substituída caso comprometa legibilidade ou personalidade.

## Paleta inicial

| Função | Cor | Hex |
|---|---|---|
| Títulos | Branco azulado | `#EAF7FF` |
| Texto comum | Azul-cinza claro | `#A8C4D8` |
| Links/interação | Ciano elétrico | `#00E5FF` |
| CTA / ênfase | Ciano → roxo | `#00E5FF → #7C3CFF` |
| Destaques especiais | Magenta | `#E000FF` |

## Semântica visual

1. Branco azulado → informação principal.
2. Azul-cinza → informação secundária.
3. Ciano → interação.
4. Roxo → estado/ênfase visual.
5. Magenta → destaque especial.

## Direção

A paleta deve transmitir:

- tecnologia;
- imaginação;
- experimentação;
- profundidade;
- interface/holografia.

Evitar excesso de neon. A intensidade deve ser concentrada nos pontos de interação e destaque.

## Fundo

### Hero

Fundo estático ou predominantemente estático para não competir com a introdução e a esfera.

### Content

Fundo com elementos flutuantes lentos, discretos.

### Footer

Fundo monocromático, possivelmente cinza.
