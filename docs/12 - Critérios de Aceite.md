# Critérios de Aceite

## MVP geral

- [ ] O site abre sem erros.
- [ ] A página apresenta claramente o desenvolvedor.
- [ ] Header funciona.
- [ ] Navegação leva às seções corretas.
- [ ] Hero possui conteúdo final ou suficientemente representativo.
- [ ] Sobre está preenchido.
- [ ] Projetos estão preenchidos.
- [ ] Habilidades estão preenchidas.
- [ ] Contato está preenchido.
- [ ] Links externos funcionam.
- [ ] Layout funciona em mobile e desktop.

## Header

- [ ] Logo retorna ao início.
- [ ] Links possuem destinos corretos.
- [ ] Estado após rolagem é visualmente consistente.
- [ ] Controles de tema/idioma funcionam, caso implementados.

## Hero

- [ ] Nome, cargo e resumo são imediatamente perceptíveis.
- [ ] CTA principal é identificável.
- [ ] Esfera não encobre o conteúdo.
- [ ] A animação não prejudica leitura.
- [ ] Existe comportamento aceitável sem hover.

## Esfera

- [ ] Estado inicial é visualmente estável.
- [ ] Cursor próximo produz reação.
- [ ] Influência roxa cresce progressivamente.
- [ ] Afastar cursor inicia recuperação.
- [ ] Não existe vazamento perceptível de recursos ou degradação grave de performance.
- [ ] Reduced motion possui fallback.

## Conteúdo

- [ ] Projetos são compreensíveis sem explicação externa.
- [ ] Tecnologias são identificadas.
- [ ] Habilidades não são apenas decorativas.
- [ ] Informações importantes não dependem de animação.

## Acessibilidade

- [ ] Navegação por teclado funciona.
- [ ] Foco é visível.
- [ ] Contraste foi validado.
- [ ] Imagens possuem tratamento adequado de texto alternativo.
- [ ] `prefers-reduced-motion` foi considerado.

## Performance

- [ ] Assets foram otimizados.
- [ ] Animações foram testadas em máquina/dispositivo de menor capacidade.
- [ ] Não há animação desnecessária em elementos fora da área relevante.
