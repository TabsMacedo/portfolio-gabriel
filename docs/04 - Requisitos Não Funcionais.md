# Requisitos Não Funcionais

## Performance

- NFR-01 — A página deve carregar rapidamente em conexões comuns.
- NFR-02 — Animações não devem causar travamentos perceptíveis.
- NFR-03 — Imagens e assets devem ser otimizados.
- NFR-04 — A esfera/interação do Hero deve evitar consumo excessivo de CPU/GPU.
- NFR-05 — Elementos decorativos devem poder ser reduzidos ou desativados quando necessário.

## Responsividade

- NFR-06 — O layout deve funcionar em desktop, tablet e mobile.
- NFR-07 — O menu deve adaptar-se a telas pequenas.
- NFR-08 — O elemento visual do Hero não deve comprometer a leitura do conteúdo em mobile.

## Acessibilidade

- NFR-09 — Contraste de texto deve ser suficiente.
- NFR-10 — Todos os controles devem possuir nomes compreensíveis.
- NFR-11 — Navegação por teclado deve ser possível.
- NFR-12 — Foco de teclado deve ser visualmente identificável.
- NFR-13 — Informações essenciais não devem depender apenas de cor.
- NFR-14 — Respeitar `prefers-reduced-motion`.
- NFR-15 — Imagens informativas devem possuir texto alternativo adequado.

## Usabilidade

- NFR-16 — O visitante deve entender a finalidade de cada seção sem esforço excessivo.
- NFR-17 — Interações decorativas não devem competir com CTAs e conteúdo.
- NFR-18 — Links e botões devem possuir estados de hover, focus e active quando aplicável.

## Compatibilidade

- NFR-19 — Testar navegadores modernos relevantes.
- NFR-20 — O site deve possuir comportamento aceitável quando recursos gráficos avançados não estiverem disponíveis.

## Manutenibilidade

- NFR-21 — Componentes visuais devem ser reutilizáveis quando houver repetição.
- NFR-22 — Conteúdo e dados dos projetos devem ser fáceis de atualizar.
- NFR-23 — Decisões experimentais devem ficar isoladas o suficiente para poderem ser substituídas.
