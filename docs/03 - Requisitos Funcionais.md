# Requisitos Funcionais

## Navegação

| ID | Requisito | Prioridade |
|---|---|---|
| RF-01 | O site deve possuir navegação para Início, Sobre, Projetos, Habilidades e Contato. | MVP |
| RF-02 | Cada item do menu deve levar à seção correspondente. | MVP |
| RF-03 | A logo deve retornar o visitante ao início/Hero. | MVP |
| RF-04 | A navegação deve continuar utilizável durante a rolagem. | MVP |
| RF-05 | A navegação deve indicar de forma compreensível onde o usuário está, quando aplicável. | P1 |

## Personalização

| ID | Requisito | Prioridade |
|---|---|---|
| RF-06 | Deve existir controle de tema claro/escuro se o modo claro for mantido. | P1 / Pendente |
| RF-07 | Deve existir controle de idioma português/inglês se a internacionalização for mantida. | P1 / Pendente |
| RF-08 | A troca de tema/idioma deve fornecer feedback visual claro. | P1 |

## Hero

| ID | Requisito | Prioridade |
|---|---|---|
| RF-09 | O Hero deve apresentar nome, profissão e resumo. | MVP |
| RF-10 | O Hero deve oferecer acesso às ações consideradas principais. | MVP |
| RF-11 | O Hero deve possuir um elemento visual de destaque. | MVP |
| RF-12 | Deve existir uma ação visual para descer até o conteúdo. | P1 |
| RF-13 | O elemento visual deve reagir à aproximação do cursor em dispositivos com ponteiro. | P2 |
| RF-14 | A influência roxa deve aumentar progressivamente durante a interação. | P2 |
| RF-15 | Ao afastar o cursor, o elemento deve retornar progressivamente ao estado inicial. | P2 |
| RF-16 | A interação deve ter alternativa ou degradação adequada em dispositivos sem hover. | P1 |

## Conteúdo

| ID | Requisito | Prioridade |
|---|---|---|
| RF-17 | Deve existir seção Sobre. | MVP |
| RF-18 | Deve existir seção Projetos. | MVP |
| RF-19 | Cada projeto deve apresentar informação suficiente para compreender seu objetivo. | MVP |
| RF-20 | Deve existir seção Habilidades. | MVP |
| RF-21 | Deve existir seção Contato. | MVP |
| RF-22 | Links externos devem abrir destinos corretos. | MVP |

## Footer

| ID | Requisito | Prioridade |
|---|---|---|
| RF-23 | O Footer deve apresentar informações de contato. | MVP |
| RF-24 | O Footer deve utilizar uma diferenciação visual em relação ao conteúdo principal. | P1 |

## Regra geral

Nenhum requisito funcional deve depender exclusivamente de animação para transmitir informação essencial.
